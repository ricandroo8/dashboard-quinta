# Circuit SVG assets

Questa cartella contiene i tracciati della stagione Formula 1 2026 usati
dal widget Formula 1. Il nome di ogni file corrisponde al `circuitId`
restituito dall'API Jolpica/Ergast.

Fonte: [MasterPlay007/F1-Track-Layouts-SVG](https://github.com/MasterPlay007/F1-Track-Layouts-SVG)

I 23 asset provenienti da questa raccolta sono distribuiti con licenza
CC0 1.0 Universal. Il testo completo è conservato nel file `LICENSE`
della cartella.

`madring.svg` e `sepang.svg` provengono dagli asset di
[F1DB](https://github.com/f1db/f1db/tree/main/src/assets/circuits),
realizzati da Jules Roy e distribuiti con licenza
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

Se l'API restituisce in futuro un circuito senza SVG, il componente
mostra automaticamente l'icona di fallback.
